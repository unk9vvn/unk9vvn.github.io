# Biometric Authentication

## Check List

* [ ] Verify biometric enrollment and authentication policies.
* [ ] Validate sensor integrity and liveness detection.
* [ ] Test resistance to presentation and spoofing attacks.
* [ ] Protect biometric templates with encryption and access controls.
* [ ] Ensure biometric data is not stored as reversible images.
* [ ] Test fallback authentication and account recovery controls.
* [ ] Enforce retry limits, lockout, and anti-brute-force protections.\
  Secure biometric data in transit and at rest.
* [ ] Review authentication logs, alerts, and audit trails.
* [ ] Validate privacy, retention, deletion, and consent requirements.
